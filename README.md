# OUTLAW CITY

Roblox open-world cops-vs-criminals driving game (PC + mobile).

- The live Roblox Studio place is the source of truth; code is edited in Studio via the Studio MCP (no Rojo).
- `src/` is a read-only snapshot of the place's scripts, exported after each tested milestone.
- Docs: [Architecture](docs/ARCHITECTURE.md) · [Roadmap](docs/ROADMAP.md) · [Progress](docs/PROGRESS.md) · [Test checklist](docs/TEST_CHECKLIST.md) · [AI team](docs/AGENTS.md)

## Controls (prototype)

| Action | Keyboard | Gamepad | Touch |
|---|---|---|---|
| Spawn car | V / Spawn Car button | D-pad up | Spawn Car button |
| Throttle / brake-reverse | W / S (or arrows) | RT / LT or left stick | GAS / BRAKE (or thumbstick) |
| Steer | A / D (or arrows) | Left stick | Thumbstick |
| Handbrake | Space | X | DRIFT |
| Enter car | E (prompt) | Y | Tap prompt |
| Exit car | F | B | EXIT |
